**Project:** Chromapages Marketing / Business Website

**Status:** Pre-copy / pre-wireframe content authority  
**Primary audience:** Growth-minded service businesses  
**Primary objective:** Qualified Project Fit conversations  
**Secondary objective:** Digital Elevation Audit inquiries  
**Core narrative:** Your business has evolved. Your website should show it.  
**Core value:** Bring the digital presence up to the level of the business.  
**Proof doctrine:** Evidence before adjectives.  
**Operating standard:** Look Premium → Convert Clearly → Load Fast → Launch Clean → Keep Improving

---

# 1. Purpose

This document defines the content requirements for the Chromapages v1 website.

It sits between:

**Strategy → Sitemap / User Flows → Content Matrix → Copywriting → Design / CMS → Build**

The content matrix determines:

- what each page must accomplish
- who each page is primarily for
- which buyer state it serves
- the primary message
- the required content modules
- the proof needed
- the primary and secondary CTA
- the Sanity content source
- the SEO role
- the content status
- launch dependencies

This is not final public copy.

It is the **content architecture and production control document** that final copy must follow.

---

# 2. Content Doctrine

Every page and section should perform a specific commercial job.

The default buyer progression is:

> **Recognition → Education → Authority → Proof → Intent → Conversion**

The website narrative is:

> **Digital mismatch → Business consequence → Dependable solution → Chromapages Standard → Evidence → Defined offer → Next step**

The content system must avoid:

- feature dumping
- generic agency language
- unsupported superlatives
- fake proof
- repetitive service descriptions
- unnecessary jargon
- multiple competing CTAs
- filler sections added only for visual rhythm

# 37. Content Quality Gate

Before copy is approved:

## Relevance

- Does a real ICP buyer care?
- Is the page talking about a real buying situation?

## Clarity

- Is there one primary message?
- Can the buyer understand the next step?

## Specificity

- Could another agency publish this unchanged?
- Does it sound like Chromapages?

## Proof

- Are factual claims supported?
- Is classification correct?
- Are permissions handled?

## Commercial

- Does the content advance recognition, proof, fit, or action?
- Is the CTA appropriate to intent?

## Brand

- Does it reinforce the Digital Mismatch narrative?
- Does it support the Chromapages Standard?
- Does it preserve Evidence Before Adjectives?

If a section fails two or more categories:

**revise before design.**
