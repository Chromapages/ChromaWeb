# Chromapages Marketing Website

## Overview
This project is the official marketing website for **Chromapages**, a premium digital design and development studio. The website is the public-facing sales asset for the business. Its job is to clearly communicate what Chromapages does, who it serves, why it is different, and how qualified leads can take the next step.

This is not just a brochure site. It is meant to support lead generation, sales qualification, trust-building, and future growth through service pages, case studies, landing pages, and SEO content.

## Purpose
The website exists to help Chromapages:

- attract qualified businesses looking for websites, landing pages, web apps, and ongoing support
- convert visitors into discovery calls and lead form submissions
- establish premium positioning in the market
- communicate a clear process and credible offer structure
- create a scalable foundation for future pages, verticals, and campaigns

## Business Role
The website should function as:

- a **sales tool** that moves visitors toward a call or inquiry
- a **qualification layer** that filters out poor-fit leads
- a **trust asset** that shows proof, process, and clarity
- a **growth foundation** for future marketing efforts

## Core Positioning
Chromapages builds modern websites and web apps that help businesses get more customers.

Key differentiators:

- built to convert
- fast on mobile
- clear process
- launch-ready QA
- tracking and measurement
- ongoing support after launch

## Primary Goals
- Increase discovery call bookings
- Increase qualified contact submissions
- Improve trust and perceived credibility
- Support outreach, referrals, SEO, and paid traffic

## Audience
Primary audience:
- growth-minded SMBs and local businesses that need better lead generation and a stronger online presence

Secondary audience:
- startups and founders who need marketing websites, landing pages, MVP sites, or ongoing digital support

## Recommended Tech Stack
This project is intended to be built with:

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**

Optional supporting systems:
- headless CMS for structured content
- GA4 for analytics
- Meta Pixel and other ad platform pixels if campaigns are active
- calendar booking integration
- form handling and spam protection

## Suggested Content Model
Structured content should support:

- analytics tracking
- staging and preview deployment support

## Setup Instructions
These are baseline setup instructions for the development environment.

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build For Production
```bash
npm run build
```

### 4. Start Production Preview
```bash
npm run start
```
