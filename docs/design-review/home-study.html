Design notes · outside page composition

Hierarchy, evidence and responsive behavior.

H1 · Understand the mismatch

The headline/body come from copy-review §4 and express the locked service-business audience and website/business-quality mismatch. They remain proposed wording, not final copy approval. One primary action leads to /contact; its wording is a later copy decision. “Digital Design Elevated.” remains an existing brand line; this proposal does not retire it.

H2 · Standards are principles

Owner wording preserved exactly. Core §§4–8 and11 govern typography, grid and one upper-right Page Stack. Desktop: five columns of copy/seven of standards. Below1024: copy/actions before flat standard rows. The longer headline uses core heading-1 at900 weight; no new type token, rotated layer, fake image or measured claim.

H3 · Empty and populated proof

The visible Work module is the honest empty/unavailable variant from copy-review §7. It does not assert that the live CMS was inspected. When authorized real records exist, replace the message with an eight-column approved image/four-column context feature, persistent “View project” link and explicit client/concept classification. Mobile: image, context, action. Missing image/results are omitted; no placeholder evidence is manufactured.

H4 · Relevance before an unapproved roster

Need statements come from copy-review §9. They describe the visitor, not new services. Approved service choices and Website Rescue Sprint terms are Unknown. No prices, package substitutions, turnaround promises or additional offer categories are shown.

H5 · Controlled engagement without invented terms

The process region presents questions from the copy review instead of inventing scope/change/support answers or contractual delivery stages. Actual operating procedures remain a source dependency. Core §13 keeps this reading section light and reserves Ink for the final action/footer.

H6 · Navigation and input modes

Inline navigation at1024 and above; native in-flow Menu below it, with no breakpoint hole, focus trap, overlay or hover-only links. Real route destinations are retained. Keyboard focus is visible; closed native disclosure content leaves traversal. CTA labels describe an inquiry, never a booked call.
