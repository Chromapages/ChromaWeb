## 6. Asset Rules

### File Naming
Use clean, descriptive names:
- `chromapages-logo-primary.svg`
- `case-study-hvac-site-homepage.webp`
- `og-default-chromapages.jpg`

### Formats
- logos: SVG preferred
- screenshots/images: WebP or optimized PNG/JPG as appropriate
- OG images: JPG/PNG based on workflow

### Storage
Keep assets organized by category:
- `/brand`
- `/projects`
- `/seo`
- `/legal`
- `/about`

---

## 7. Recommendation

Before build completion, make sure every launch-critical asset has:
- an owner
- a final file
- a known location
- confirmation that it is approved for use
