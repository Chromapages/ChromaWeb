# Wireframes

## Purpose
This document provides low-fidelity structural wireframe notes for the Chromapages marketing website. These are text-based content and layout outlines only.

This document is intentionally non-visual and non-stylistic so it does not conflict with separate design documentation. It exists to define hierarchy, section order, content grouping, and expected user movement on each page.

## Reusable Section Notes

### Core Reusable Blocks
- hero
- proof strip
- service block
- project card
- FAQ block
- CTA block
- testimonial block

### CTA Placement Rule
Every key page should have:
- one early CTA opportunity
- one mid-page progression point where appropriate
- one closing CTA

### Internal Linking Rule
Each major page should naturally link to at least one of:
- contact
- pricing
- process
- work
- relevant service page
