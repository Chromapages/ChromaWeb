# Chromapages Sitemap + User Flows v1.0

## Core IA Principle

> **The Chromapages website is a progressive buyer-decision system, not a brochure hierarchy.**

The core commercial flow is:

**Digital Mismatch → Why It Matters → Chromapages Approach → The Standard → Proof → Engagement Fit → Project Fit / Audit**

Visitors may enter at different stages, but every page should advance that same underlying story.

## Work Flow

```text
Work
→ Project classification
→ Context
→ Challenge
→ Strategy
→ Design / Build
→ Launch
→ Evidence
→ Relevant Service
→ Project Fit
```

Every project must remain explicitly classified as real public work, confidential work, white-label work, concept study, internal prototype, or owned-brand work.

## Services Routing

Instead of presenting five equal capability cards, route by situation:

```text
Business has outgrown its website
→ Signature Website

Campaign needs one destination
→ Landing Page Sprint

Workflow needs a custom system
→ Digital Product Build

Live site needs ongoing improvement
→ Growth Partnership

Problem exists but scope is unclear
→ Digital Elevation Audit
```

## Signature Website Flow

```text
Recognize fit
→ Understand transformation
→ Understand scope
→ Understand the Standard
→ Reduce process anxiety
→ Evaluate proof
→ Evaluate investment
→ Project Fit
```

## Digital Product Flow

```text
Workflow / product need
→ Suitable product types
→ Paid Discovery requirement
→ Discovery deliverables
→ Build phases
→ Investment
→ Start With Discovery
```

High-uncertainty product work cannot bypass discovery.

## Digital Elevation Audit Flow

```text
Problem recognized
→ Scope unclear
→ Audit positioned as diagnostic
→ Understand evaluation areas
→ Understand deliverables
→ Understand paid-strategy model
→ Audit Inquiry
```

The Audit should never appear to be a free teardown.

## Process Flow

```text
Vendor / redesign anxiety
→ Why projects become difficult
→ Chromapages Standard
→ Engagement stages
→ Client responsibilities
→ QA / approval evidence
→ Service or Project Fit
```

Its main job is to answer:

> **Will this become another chaotic redesign?**

## Wireframe Priority

Wireframe these journeys first:

1. **Home → Signature Website → Project Fit**
2. **Home → Work → Case Study → Project Fit**
3. **Home → Digital Elevation Audit → Audit Inquiry**
4. **Accounting Campaign → Industry → Audit / Signature Website**
5. **QSR Entry → Industry → Work → Project Fit**
6. **Insight → Industry / Service → Project Fit**
7. **Digital Product Build → Paid Discovery → Project Fit**
8. **Mobile Navigation → Service / Work / Project Fit**
9. **Project Fit progressive qualification**
10. **Returning visitor → direct high-intent destination**

## Final IA Rule

> **Do not make every visitor consume the whole story. Make every page capable of advancing the story from wherever they enter.**
